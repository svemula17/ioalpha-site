Built into every track

Seven skills every trainee leaves with.

Whatever technical track you pick, these run alongside it for all ten weeks. They are not electives: they are the difference between a graduate and a colleague.

01

Software Skills

Real-world coding, Git, testing, code reviews, and Agile/Scrum with Jira.

  • Real-world coding on a live project
  • Git and GitHub workflow
  • Writing and running tests
02

Communication Skills

Professional emails, meetings, status updates, and presentations.

  • Professional email writing
  • Status updates and sprint notes
  • Documentation others can follow
03

Client Communication

Gathering requirements, asking the right questions, handling escalations, and demoing your work.

  • Gathering and confirming requirements
  • Asking the right questions
  • Writing up what was agreed
04

Business Ethics

Data security, confidentiality, NDAs, POSH awareness, and professional integrity.

  • Data security basics for engineers
  • Confidentiality and client data
  • NDAs and what they mean for you
05

AI Literacy

Using AI tools to work faster, safely and responsibly.

  • AI assistants for coding and writing
  • Prompting that gets useful answers
  • Checking and owning AI output
06

Business Domain Basics

How companies run: finance, supply chain, and HR, and how software supports them.

  • Finance basics for engineers
  • Supply chain and operations basics
  • HR and how organisations are structured
07

Career Readiness

Resume building, LinkedIn profile, mock interviews, and understanding offer letters.

  • Resume rebuilt around real work
  • LinkedIn profile that gets found
  • Mock interviews with working engineers
